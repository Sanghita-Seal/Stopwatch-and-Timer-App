# Timer & Stopwatch

A small dark theme React app with two tabs: Timer and Stopwatch.

## How It Works

- Timer: set hours, minutes, and seconds, then start, pause, or reset.
- Stopwatch: start, pause, reset, and save lap times.

## What We Used

- React
- TypeScript
- Vite
- CSS for simple dark styling

## Run

```bash
npm run dev
```
